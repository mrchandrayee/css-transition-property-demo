CSS Transition Property
with & without

❌ Without Transition

Beautiful Mountains

Hover this card. Everything changes immediately without animation.

.card:hover {
  transform: translateY(-18px);
  box-shadow: 0 30px 60px rgba(0,0,0,.35);
}

✅ With Transition

Beautiful Mountains

Hover this card. Every property animates smoothly.

.card {
  transition: transform 0.45s ease,
              box-shadow 0.45s ease;
}

.card:hover {
  transform: translateY(-18px);
  box-shadow: 0 30px 60px rgba(0,0,0,.35);
}
